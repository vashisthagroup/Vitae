## 🤖 AI Screening Feature

- **Gemini Integration** - Evaluates candidate responses
- **Fit Score** - 0-100 based on job requirements
- **Smart Categorization** - Auto-schedule interviews if score > threshold
- **Instant Feedback** - Candidates get results immediately

### Setup

```
1. Get API key from Google AI Studio
2. Add to .env.local: NEXT_PUBLIC_GEMINI_API_KEY=your_key
3. Test: POST /api/screening/evaluate
```
