🚀 VITAE PRODUCTION DEPLOYMENT COMMANDS
==========================================

STEP 1: DEPLOY FRONTEND TO VERCEL (5 minutes)
=============================================

Copy and paste these commands in order:

1. Install Vercel CLI:
   npm install -g vercel

2. Login to Vercel (use GitHub):
   vercel login

3. Deploy to production:
   vercel deploy --prod

EXPECTED RESULT:
✓ Your app will be live at: https://vitae.vercel.app
✓ Dashboard at: https://vercel.com/dashboard
✓ Auto-updates on every git push


STEP 2: DEPLOY BACKEND TO RAILWAY (3 minutes)
==============================================

Go to: https://railway.app

1. Click "New Project"
2. Select "Deploy from GitHub repo"
3. Choose: vashisthagroup/Vitae
4. Add Environment Variables:
   - DATABASE_URL = sqlite:./dev.db
   - MAILGUN_API_KEY = <your_mailgun_key>
   - MAILGUN_DOMAIN = <your_mailgun_domain>
5. Click "Deploy"
6. Done! Auto-deploys on every git push

EXPECTED RESULT:
✓ Backend running at: https://vitae-production.up.railway.app
✓ Database: SQLite (included)
✓ Automatic deployments enabled


STEP 3: SETUP EMAIL (OPTIONAL - 10 minutes)
==========================================

Go to: https://mailgun.com

1. Sign up (free tier, no credit card)
2. Get API Key from Dashboard
3. Add to Vercel environment variables:
   - MAILGUN_API_KEY
   - MAILGUN_DOMAIN
4. Add same to Railway environment variables
5. Test email sending

FREE TIER: 5,000 emails/month


STEP 4: SETUP AI SCREENING (OPTIONAL - 5 minutes)
================================================

Option A: Ollama (Free, Local)
   Download from: https://ollama.ai

   Runs at: http://localhost:11434

   No AI required
   Completely free
