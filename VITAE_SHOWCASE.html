How Vitae Works

The complete recruitment automation workflow

1

Candidate Applies

Candidate submits application through Global Job Search portal or external job boards. Application automatically enters the pipeline.

2

AI Screening Begins

Candidate answers custom screening questions. AI evaluates responses and calculates a fit score based on role requirements.

3

Smart Categorization

Fit score compared to role's auto-schedule threshold (typically 75%). High scorers automatically move to interviews; low scorers receive feedback.

4

Calendar Sync

Interview slots are booked automatically, calendar invites sent, and reminders triggered. Recruiter sees everything in unified schedule.

5

Recruiter Manages

Recruiter reviews pipeline, reschedules if needed, takes notes on candidates, and moves top performers to next round.

Key Differentiators

Separate Login Flows

Recruiters and candidates use completely separate accounts and experiences. No mixing of user types, no confusion, maximum security.

Each role sees only what they need to see and can only perform actions appropriate to their role.

  • Recruiter login → Dashboard, Pipeline, Roles, Scheduling, Admin Approvals
  • Candidate login → Job Search, Applications, AI Screener, Profile
🔐

World-Class Design

Clean, intuitive interface with clear button-focused navigation. Premium ATS aesthetic inspired by the best platforms in the world.

Minimalist design reduces cognitive load and lets recruiters focus on what matters: finding great talent.

✨

Permission Layers

Distinguishes between Recruiters and Administrators. Admins control job approvals, rule changes, and system settings.

Built-in governance ensures compliance and prevents unauthorized changes to critical configurations.

⚙️

Confirmation Modals

Critical actions require confirmation. Bulk operations show how many records will be affected before proceeding.

Prevents accidental changes and keeps recruiters in control of the system at all times.

Getting Started

Deploy Vitae in minutes

Quick Start:

git clone https://github.com/vashisthagroup/Vitae.git
cd vitae
npm install
npm run dev
# Visit http://localhost:3000

Environment Setup:

  • Copy .env.example to .env.local
  • Add your Gemini API key for AI screening
  • Configure LinkedIn OAuth credentials (optional)
  • Set up your database connection
  • Run migrations and seed initial data

Next Steps:

  • Customize branding and colors to match your company
  • Set up your database (PostgreSQL recommended)
  • Configure email service for candidate notifications
  • Set up calendar integrations (Google Calendar, Outlook)
  • Train your team on the platform
